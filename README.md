# Viernes 13 · La hora extraña

Una experiencia de misterio en español, diseñada para teléfonos y escritorio. Incluye 13 cartas de la suerte, tres historias interactivas y sonido opcional.

## Publicación con GitHub Pages

En Settings → Pages selecciona **Deploy from a branch**, rama **main**, carpeta **/ (root)** y pulsa **Save**.

La dirección esperada después de publicarse es https://dieguitobot.github.io/Viernes13/.

No requiere instalación ni compilación. Los archivos index.html, style.css y app.js se sirven directamente.
