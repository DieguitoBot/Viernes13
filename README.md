# Mi buena suerte eres tú · Viernes 13

Una dedicatoria para alguien especial, con tulipanes ilustrados y animados, un sobre que revela una carta, tres notas interactivas y una canción dedicada de Marcos Menchaca enlazada a su canal oficial en YouTube.

Diseño adaptable a teléfonos. Respeta la preferencia de movimiento reducido. No necesita compilación, cuentas ni instalación.

Los archivos de la web son `index.html`, `style.css` y `app.js` (carpeta `dist/` en la copia local). GitHub Pages sirve la rama `main`, carpeta raíz.

Web: https://dieguitobot.github.io/Viernes13/
